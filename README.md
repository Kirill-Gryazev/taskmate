# TaskMate — Telegram-бот для управления задачами

Учебный проект на Python. Бот помогает вести личный список задач:
добавлять дела, отмечать их выполненными, удалять и смотреть статистику.

## Возможности

- Добавление задач командами и через кнопки.
- Ввод нескольких задач подряд отдельными сообщениями.
- Просмотр личного списка задач.
- Выполнение и удаление задач кнопками под сообщением.
- Статистика: всего задач, выполнено и осталось.
- Хранение задач в SQLite с сохранением после перезапуска.
- Отдельный список для каждого пользователя.
- Проверка длины текста задачи: от 1 до 200 символов.
- Отмена ввода через /cancel.

## Технологии

- Python 3.13
- aiogram 3

## Файлы проекта

- main.py — обработчики команд, кнопки и запуск бота.

- .env.example — пример настройки токена.
- .gitignore — исключения для Git.

## Запуск на Windows

Проверено на Python 3.13.

1. Скачайте проект и откройте терминал в его папке.
2. Создайте виртуальное окружение:

```powershell
py -3.13 -m venv .venv
```

3. Установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

4. Создайте бота в Telegram через @BotFather и получите токен.
5. Скопируйте .env.example в файл .env.
   Если .env уже существует, используйте существующий файл.
6. В файле .env замените your_bot_token_here на свой токен.
7. Запустите бота:

```powershell
.\.venv\Scripts\python.exe main.py
```

8. Откройте своего бота в Telegram и отправьте /start.

База tasks.db создаётся автоматически при запуске.
Бот отвечает, пока программа запущена и доступен интернет.
Для остановки нажмите Ctrl+C в терминале.

## Команды

| Команда | Действие |
| --- | --- |
| /start | Главное меню и выход из ввода |
| /help | Инструкция |
| /add текст | Добавить одну задачу |
| /list | Показать список задач |
| /done номер | Отметить задачу выполненной |
| /delete номер | Удалить задачу |
| /stats | Показать статистику и выйти из ввода |
| /cancel | Закончить ввод задач |

## Настройки и данные

Настоящий токен хранится в .env.
Файл .env и база tasks.db исключены из Git через .gitignore.

SQL-запросы используют параметры.
Выполнение и удаление проверяют принадлежность задачи пользователю.

Задачи сохраняются после перезапуска.
Состояние ввода хранится в памяти и сбрасывается при остановке бота.
